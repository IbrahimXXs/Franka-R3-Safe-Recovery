# 有限夹持能力背景下的任务载荷预算实验

## 1. 研究问题与适用范围

夹爪无法无限增加夹持法向力，易碎工件也可能限制夹持力及承受的轴向力、弯矩。因此，同一个机械接触状态可能存在“直接退出超过任务允许载荷，而另一条恢复路径在预算内完成”的策略差别。

本版以**较低的腕部合力预算**检验这个问题。沿用上一版刚体孔／销、接触材质、夹爪驱动、控制律、位姿命令和滑移限制，没有创建断裂模型，也没有把夹爪的实际驱动力调小。详细测量边界见[夹持与载荷物理说明](forge_budget_physical_scope_zh.md)。

3／4／5 N 是依据旧记录选取的探索性任务预算，不是已标定的材料强度或实测夹持能力。预算信号为原始 `wrist_force_n` 三轴合力模；孔→销的法向载荷总和 ΣN、接触摩擦 Z 分量、夹指法向力和腕部合力分别保留不同含义。旧记录的离线重评与新版在线执行分开保存。

## 2. 冻结的八组条件

所有条件使用 240 Hz，种子 20260913，径向间隙约 0.2 mm，25 mm 盲孔；实际有效间隙以运行时几何审计为准。每组计划两条策略：直接退出，以及 XY 回中＋姿态回正后退出。

| 作用 | 深度 mm | 孔／销有效 μs / μd | 命令倾角 | 力预算 N |
|---|---:|---:|---:|---:|
| 对齐对照 | 18 | 1 / 1 | 0° | 4 |
| 较小角度 | 18 | 1 / 1 | 1° | 4 |
| 主要候选 | 18 | 1 / 1 | 1.5° | 4 |
| 较宽预算对照 | 18 | 1 / 1 | 1.5° | 5 |
| 较浅嵌入对照 | 12 | 1 / 1 | 1.5° | 4 |
| 较低孔／销摩擦 | 18 | 0.5 / 0.5 | 1.5° | 4 |
| 更大倾角 | 18 | 1 / 1 | 2° | 4 |
| 更紧预算对照 | 18 | 1 / 1 | 1.5° | 3 |

这是有目的的机制选点，不是均匀全因子矩阵或独立重复试验。改变孔／销有效摩擦时只更换孔材质系数，销与夹爪材质、夹爪位置闭合命令均保持上一版设置。不能把这一参数变化解释为夹指摩擦变化。

## 3. 执行与中止语义

1. 新进程建立同一场景，按上一版执行材质预热、重置、夹持准备和 3 秒稳定。
2. **预算从记录的 reference 初始样本 t=0 生效**；上述准备阶段没有应用新预算，因而本实验不认证易碎件的抓取过程。
3. 对齐插入到实际目标深度 ±0.1 mm，并连续保持 0.2 s，之后固定命令深度施加 1 s 倾角渐变，再保持 1 s。
4. 同一低预算覆盖 reference、STOP、回中回正、RETREAT 和清孔保持，力矩预算仍为 1 N·m。沿用 `F≤B` 允许、`F>B` 超限的边界语义。
5. 初始样本已超限时不发出第一步任务命令。步后越界时保存原始样本和接触记录，不再发出下一步任务命令。记录超调量，不裁剪力曲线。
6. 只有参考完整、数值筛查通过、夹持关系保留且预算内到达深度门槛，才开始恢复。STOP 为已达到手部位姿保持 0.25 s；退出命令峰值速度统一 5 mm/s，速度过渡 0.5 s。
7. 两种策略使用独立新进程。离线比较实际完整参考前缀与终点；独立进程或相同种子本身都不代表状态匹配。

这是**采样监测后停止任务推进**，不是把物理力严格限制在预算内的力控制器，也不是机械臂制动验证。触发样本可以超过阈值；触发后的真实刹停峰值没有观测，不能填写为 0。

每个物理／预算条件独立运行，不因另一物理条件的对齐对照失败而删除它。如果某条件的直接分支在参考阶段已不合格，另一策略记为 `not_tested`，保留在 16 个计划分支的分母中。没有确定性重试或筛选成功轨迹。

## 4. 数据与标签

| 层级／文件 | 内容 |
|---|---|
| `study.json`、`case_plan.json`、`base_protocol.json` | 八组冻结条件、16 个计划分支、启动命令／时间／返回码、未测原因与配置来源 |
| `source/` | 实际执行的源码副本与 SHA256，续跑不允许修改冻结计划、预算或执行源码 |
| `runs/<condition>/<policy>/run.json` | 本分支条件、有效预算、几何／材质、参考和恢复质量、首次越界证据、结果及截断信息 |
| `insertion.csv`、`insertion_contacts.jsonl.gz` | 参考每步实际／命令位姿、腕部力矩、孔→销法向与摩擦力、滑移、数值重叠、原始接触点 |
| `recovery.csv`、`recovery_contacts.jsonl.gz` | 真正执行的恢复轨迹；未进入恢复时文件不存在，不能伪造零力曲线 |
| `config.json`、`scene.json`、`actuator_readback` | 场景和材质回读、关节驱动参数；这些参数不是实测夹持法向力 |
| 独立审阅目录 | 每条件／每分支表、完整前缀匹配、预算余量、分阶段曲线和只读输出一致性检查 |

首次越界保存所在阶段、样本索引、物理时间、原始腕力／力矩、深度、夹持滑移、超调量、是否初态已越界。100 ms 峰值使用完整连续同阶段窗口；零时刻的复制样本不算执行步，不足一个窗口时值为空。

分类分开表达：

- `clear_safe`：该实际执行路径完整退出，且记录的参考与恢复满足数值、夹持和预算条件。
- `reference_budget_exceeded`：插入／倾斜期间已超预算，恢复没有执行，不能当作退出失败。
- `recovery_budget_exceeded`：恢复中实际观测超预算；另存 STOP／回中回正／RETREAT 的具体触发阶段。
- `reference_grasp_limit`／`recovery_grasp_limit`：达到夹持滑移限制，和超力事件分别记录。
- `numerical_unknown`：数值无效，不能赋物理安全正负标签。
- `timeout_unknown`／`not_tested`／配对失配：保留未知或未测，不变成成功或失败。

完整前缀匹配且一条策略实际超预算、另一条安全清孔，才能形成所需的**策略相关正负对**。超限中止轨迹的峰值是已观测峰值，也是未执行完整路径峰值的下界；完整恢复成本差只对两条均完成的路径计算。两种策略都失败也不能推断所有恢复策略都不可行。

后续模型的条件应包含**实际恢复起点、预算 B 和恢复策略**。同一物理路径在不同预算下可以有不同标签，这属于任务约束变化。保留 `split_group_id` 与 `path_group_id`，将共享参考前缀的角度、预算及策略记录放在同一数据划分组中，避免把近乎相同的轨迹随机分到训练集与测试集。

## 5. 运行

在项目的 `franka-safe-recovery` 环境中：

```bash
python simulation/run_budget_study.py \
  --case-plan experiments/forge_budget_v1.json \
  --output-dir outputs/Forge-Budget-New
```

每个分支通过 `forge_budget.sh` 新启动 Isaac Sim。`--max-invocations 1` 可在首个分支后暂停核对；同一冻结实验使用 `--resume` 继续。错误或中断记录不自动重试，避免把重复运行误算为独立样本。

本次历史选点依据保存在 `outputs/Forge-Budget-Design-20260915-review/`；新版在线数据保存在 `outputs/Forge-Budget-V1-20260915/`。两者不改写任何旧研究的标签。

只读汇总与检查可以在运行期间使用，只会打开已完成分支；最终完成后再刷新一次：

```bash
python simulation/summarize_budget_study.py \
  --study-dir outputs/Forge-Budget-New \
  --output-dir outputs/Forge-Budget-New-review --plots
python simulation/validate_budget_output.py \
  --study-dir outputs/Forge-Budget-New \
  --output-dir outputs/Forge-Budget-New-review --deep
python simulation/analyze_budget_comparisons.py \
  --study-dir outputs/Forge-Budget-New
```

最终报告见[本次中文结果](../outputs/Forge-Budget-V1-20260915-review/results_zh.md)；`cases.csv` 保留八组条件，`branches.csv` 保留 16 个计划策略分支，`schema.json` 解释单位与空值。
