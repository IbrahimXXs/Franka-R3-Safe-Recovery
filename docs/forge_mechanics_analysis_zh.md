# 本轮参数分析的判据

本轮是用于寻找机理和改进实验设计的探索性仿真。每个条件一次，不把条件之间的差异写成统计显著性，也不预设“越深/摩擦越大，退出力必然越大”。执行协议见 [实验说明](forge_mechanics_study.md)。

## 要回答的问题

1. **倾斜是否改变接触和退出阻力？** 将 2° 条件与同深度、同摩擦的 0° 对照比较。检查实际倾角、实际深度变化、法向载荷、摩擦分量，再比较退出力。0° 条件自身的跟踪误差和接触不能忽略。
2. **嵌入长度如何影响结果？** 目标深度用来组织条件，实际终端深度及导向长度估计用来解释结果。孔深固定为 25 mm，撤出速度与速度起步曲线统一；受载孔壁两侧的加权中心间距是另一项测量，不能直接用孔深或插入深度替代。不同深度仍经历不同长度的插入历史，因此这是当前协议下目标深度的总效应，不是实际接触间距的独立因果估计。
3. **较大的摩擦系数是否形成更明显的受阻状态？** 分别比较 `(0.5,0.5)`、`(0.75,0.75)`、`(1,1)`；用 `(1,0.5)` 探索静/动摩擦分离。姿态或法向载荷随参数改变时，不把退出力之比直接解释为摩擦系数之比。
4. **调姿是否降低整个恢复过程的代价？** 只有整段插入回放和分支端点均匹配，才比较连续直退与 XY 回中加姿态对齐。分别报告 STOP、对齐、实际撤出阶段以及整个恢复过程的峰值。

## 力和卡滞证据

- 同时报瞬时腕部力峰值、完整 100 ms 窗口平均峰值、接触轴向阻力、清孔结果和运动量。腕部力模长不能等同于纯轴向拔出力。
- “有峰值”不能单独证明卡死。较强证据需要在退出命令继续移动时，实际退出位移很小，并同时存在持续的接触载荷和阻力。
- 分别取出的法向阻力峰值和摩擦阻力峰值可能发生在不同时刻，不能相加当作总峰值。需要比较同一采样或同一时间窗口。
- 20 N/1 N·m 是本轮已有的操作预算，并非机器人硬件极限。若记录不足以触及该预算，仍可分析更低任务阈值的设计空间；事后挑选的阈值属于探索性分析，不能冒充已独立验证的安全上限。

## 数据可信度和结论边界

- 超过穿透筛查阈值的结果标记为数值无效；这不是物理卡死反例。当前筛查阈值为实际径向间隙的 25%，只是数值检查，不能证明碰撞已达到真实材料精度。
- 夹持滑动与销孔退出失败分开记录。提前终止的力曲线只有已执行部分，不能作为完成退出所需的全部峰值。
- 缺失、未执行或回放失配的策略结果保留为未知。某一策略失败不代表状态不可恢复；两种策略都失败也只代表这两种已测试策略失败。
- 必要时用独立目录复查关键条件及其 0° 对照的物理频率敏感性。改变频率也改变了本基准的控制更新频率，而且重置后状态可能不同；不能仅凭一个更高频率结果宣称数值收敛。
- 当前模型只有刚体接触和摩擦，不包含塑料孔的塑性形变、磨损或新凸起生成。结果可以支持接触/控制机理和下一轮实验选择，不能直接确认这些损伤机制或真实材料参数。
