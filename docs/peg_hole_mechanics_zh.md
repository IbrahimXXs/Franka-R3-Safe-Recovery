# 嵌入长度、摩擦与销孔卡滞：理论分析笔记

本笔记用于解释和设计实验，不修改现有物理模型，也不把理论边界直接转成数据标签。

**后续实现说明（2026-09-15）：** 下文“需补充的测量”描述的是旧 FORGE 数据的局限。新的 [定深度机理实验](forge_mechanics_study.md) 已分别保存逐点法向接触与摩擦锚点、几何导向跨度及各阶段力；离线分析还区分孔口边缘和内壁受载区。旧 CSV 的缺失信息不能据此补回。新的测量也不包含塑料损伤或真实材料刚度标定。

## 1. 核心结论

实际嵌入长度应作为分析变量，但退出力不必随长度单调增加。必须同时确定接触模式、实际倾角、外加力矩以及系统柔顺性。

- 倾斜销的局部两点接触：长度改变接触力的力臂，固定外加力矩时，接触间距增大反而可降低法向载荷。
- 固定实际倾角并增加嵌入长度：可能超过几何容许范围；力有多大还取决于机器人和材料的柔顺性，不能由几何单独求出。
- 过盈配合或分布式抱紧：在接触压力近似不变时，摩擦随实际受压接触面积增大。

因此，上轮“长度增加导致横向错位增加”的解释只描述固定倾角下的几何趋势，不能推出一般的拔出力规律。

## 3. 必须分开的长度

| 符号 | 含义 | 当前数据情况 |
|---|---|---|
| H | 孔的总深度 | 现有盲孔约25 mm；不是接触长度 |
| d(t) | 销端相对孔口的轴向实际插入深度 | 已记录 `depth_mm`；必须保留符号、参考点和实际姿态 |
| Lg(t) | 销的全径圆柱段与孔直壁的轴向重叠跨度 | 可由几何与位姿估算，需扣除倒角；不等于整段都在接触 |
| ell(t) | 两个主要受载接触区之间的轴向间距 | 应由实际接触位置计算，现有CSV没有保存足够的逐接触点信息 |

当前销总长50 mm，端部各约0.5 mm倒角；孔口约1 mm倒角。近轴向时，20 mm插深对应的全径直壁重叠约18.5 mm；14.05 mm插深约对应12.55 mm。这只是几何估算，不能代替真实接触间距。

## 4. 一个可核查的两点接触模型

以下是本笔记的简化力平衡推导。假设小倾角、直孔壁、准静态向上退出、两个接触处均沿竖直方向滑动，忽略倒角、惯性和材料损伤。

令两个对角接触点在截面内的位置为 `(x,z)=(+b,+ell/2)` 和 `(-b,-ell/2)`。上接触的法向力向左为N1，下接触向右为N2；两个摩擦力均向下。外侧向力P向右；M是关于接触中点、朝压紧这对接触方向的外部总力矩。

平衡关系为：

\[
N_1-N_2=P,\qquad
M=\frac{\ell}{2}(N_1+N_2)-b\mu_kP.
\]

于是滑动摩擦阻力为：

\[
F_{\rm friction}=\mu_k(N_1+N_2)
=\frac{2\mu_k(M+b\mu_kP)}{\ell}.
\]

需要N1、N2均非负，否则该两点接触分支不可成立。M包含偏心施力产生的力矩；不能不变换参考点就代入腕部力矩模长。若P=0，则：

\[
N_1=N_2=\frac{M}{\ell},\qquad
F_{\rm friction}=\frac{2\mu_kM}{\ell}.
\]

这给出一个反例：固定M和摩擦系数、在可行的两点接触构型之间比较，增大ell会降低摩擦。比较时实际倾角通常也会变化。

静止时应使用摩擦不等式 `|Ti| <= mu_s Ni`，不能一律取等号。上述F是轴向接触摩擦，不是完整腕部合力；实际拔出驱动力还涉及重力、惯性等。

## 5. 固定倾角与有限刚度

令c为本项目的单边径向间隙，theta为实际倾角。小角度下，可用以下量级关系理解几何挤压：

\[
L_g|\theta|\lesssim2c.
\]

该式是直壁、近二维几何的容许量级，不是完整三维碰撞判据。若强行保持theta并增大Lg到超出容许范围，理想无穿透刚体模型没有相应构型；这不等于已经得到无限大物理接触力。

若另外引入两端对称的等效法向刚度kn，可以构造解释性的近似：

\[
\delta\approx\frac{[L_g|\theta|-2c]_+}{2},\quad
N\approx k_n\delta,\quad
F_{\rm friction}\approx2\mu_k k_n\delta.
\]

这里的delta是显式弹性模型中的压缩，不是PhysX报告重叠；kn也不是当前仿真已经标定的参数。旋转控制力矩近似满足 `Mrot = Ktheta (theta_command - theta_actual)`（准静态、指定参考系下）；关于接触中点的总M还包括侧向和偏心拉力的力臂贡献。实际接触、姿态和支承共同决定结果，退出力可能非单调。

## 6. 过盈配合是另一种模型

当整个圆周形成分布式接触，纯轴向滑动摩擦可写为：

\[
F_{\rm friction}=\int_{A_c}\mu_k p(s)\,dA.
\]

若接触压力p和mu近似均匀、接触覆盖直径D的整个圆周且轴向长度为Lc，则由接触面积积分得到：

\[
F_{\rm friction}\approx\mu_k p\pi D L_c.
\]

此时固定p下，受压长度增加确实会增大退出摩擦。但当前模型是正间隙刚体销孔，不能默认存在这种均匀抱紧压力。塑料变形后可能是局部接触，必须使用实际压力分布，而非直接套满圆周公式。

## 7. 卡滞与自锁不要混作同一种失败

本笔记沿用所引销孔论文的区分：jamming侧重施力和力矩使运动受阻；wedging侧重撤掉外部载荷后仍可能维持的摩擦自锁。它们均不直接等于本项目“给定策略库和预算内恢复失败”的标签。

Lan等2023第5.2节讨论的经典二维近似自锁必要条件包括 `l <= mu Dpeg`，以及 `theta >= C/mu`，其中C为直径间隙比 `(Dhole-Dpeg)/Dhole`，不是本项目以mm计的单边间隙。其l是该理想图中的嵌入长度，使用前必须统一几何定义。

这提示自锁可能发生在特定的较浅深度和较大倾角组合，不能只搜索更深插入。上述条件不是充分条件，也不适用于直接给当前三维、带倒角、存在数值重叠的轨迹贴自锁标签。

## 8. 对实验和数据的具体启发

1. 将实际深度d、几何重叠Lg、接触间距ell作为不同变量；分别记录扰动触发、倾角完成、开始恢复、退出力峰值时的取值。
2. 实际深度会被卡滞反过来影响。目标深度和触发深度是实验输入，实际达到深度是输出；未达到目标的情况应单列，不能将目标当作实际嵌入长度。
3. 主实验继续保留连续插入路径。可另设小型机理实验：先对齐到指定深度，再在深度命令保持时缓慢施加倾角并测试退出；它与连续插入研究的协议不同，须独立统计。
4. 在相同间隙和摩擦下绘制 `实际深度 × 实际倾角` 图，着色为100 ms退出轴向阻力，并按接触模式、控制刚度和数值有效性分组；每次恢复过程也应画 `Fexit(d)`，观察退出过程中接触模式的变化。
5. 比较“相同实际姿态、不同插入历史”的状态，以判断是否需要引入历史依赖材料模型；不能用不同姿态下的力差异证明材料损伤记忆。

### 现有数据与需补充的测量

已保存：实际深度和姿态、命令倾角、接触合力/合力矩、法向载荷总和、腕部信号、速度、数值重叠及各阶段恢复结果。

需要补充：各接触区位置、法向方向及法向载荷，分别保存接触法向与摩擦贡献，接触区之间的间距、接触力矩参考点，以及控制命令的分量。

底层 `simulation/contact.py` 已读取接触点、法向及摩擦流，但主要聚合后输出；`simulation/forge_backend.py` 没有把这些逐接触信息保存到CSV。因此旧数据无法精确重建两个真实接触区。PhysX多个数值接触点应按几何分区分析；法向与摩擦数据流也不能按数组下标直接一一配对。

这些补充观测可以检验“深度变化是否改变接触间距或法向载荷”，而不是仅拟合深度与腕力峰值的相关性。
