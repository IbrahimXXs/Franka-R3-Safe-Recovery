# 低力预算在线实验：依据历史轨迹的设计建议

**以下是事后筛选与新实验建议，不是低预算闭环运行结果。** 已对原24条件、240 Hz边界3条件、480 Hz边界2条件的已关闭原始CSV，分别施加2、3、4、5、6、8、10 N离线阈值；共203个“来源条件×预算”记录。不同目录中的相同条件可能复用相同轨迹，29不是独立重复次数。

## 建议先验证的4个条件

全部使用240 Hz、目标深度18 mm、有效接触静/动摩擦系数1/1、现有0.2 mm名义径向间隙、5 mm/s退出与0.5 s速度渐变；保持接触模型不变。每个条件比较连续直接退出与从匹配起点执行的“XY回中心＋姿态回正”。

| 目标倾角 | 全程腕力预算 | 用途 | 历史筛选结果 |
|---|---:|---|---|
| 1.5° | 4 N | 首要策略分离案例 | 参考可接纳；直退RETREAT超限；回中心＋回正全程未超限且退出 |
| 1.5° | 5 N | 同一姿态的较宽预算对照 | 两策略全程均未超限且退出 |
| 0° | 4 N | 对齐姿态对照 | 两策略全程均未超限且退出 |
| 1° | 4 N | 中等倾角对照 | 两策略全程均未超限且退出 |

4 N由旧数据选出，须明确标记“事后设计阈值”，并通过新在线运行检验；不能作为原历史数据预先规定的成功标签。新记录应保留第一次超限时刻、阶段、实际腕力及停止后状态，不能只保存“最终是否退出”。

## 为何选择1.5°与4 N

240 Hz边界案例`m_d18_fs100_fd100_a1p5`的原始腕力最大值：

| 范围 | 峰值 |
|---|---:|
| 完整参考过程 | 3.556881 N |
| 两策略共同STOP | 3.754587 N |
| 直接退出全程／RETREAT | 4.583499 N |
| 回中心＋回正全程 | 3.754587 N |
| 回中心＋回正的REALIGN阶段 | 2.282222 N |
| 回中心＋回正后的RETREAT阶段 | 1.150869 N |

因此，严格使用原判据`force > budget`时，历史策略分离区间为 **[3.754587, 4.583499) N**。区间下界同时覆盖完整参考与回正策略的全程负载，而不是只比较退阶段峰值。

4 N历史首次直退超限位于恢复CSV的样本173、RETREAT阶段，恢复开始后约0.720833 s；该步实际腕力为4.541491 N，实际深度18.091173 mm、命令深度17.123243 mm。这说明“4 N”应解释为采样触发停止的门槛；单步可能越过门槛，并不构成连续时间不超过4 N的硬力上限。原轨迹后续曾完成退出，不意味着在4 N触发停止后的新轨迹也能完成。

3 N不适合作为同一完整协议的恢复分离预算：历史参考阶段已在hold中先超3 N，此时原恢复起点不应被视为可达。若后续另设“参考较宽、恢复较紧”的分阶段预算，应作为新的协议单独定义，不能混入本次全程同一预算的结果。

## 历史扫表的主要结果

- 原24条件：2 N时17个参考可接纳；3–10 N时20个参考可接纳。这些可接纳参考的连续直退历史均完成且未超预算。其余4个18 mm／2°条件仍因参考夹持门槛或更早的力门槛而不合格，不能当作拔出力负例。3–10 N时只有7组策略匹配，其余13组重放不匹配仍为未知。
- 240 Hz边界：2 N时仅0°参考可接纳；3 N时0°和1°可接纳；4 N时三个参考都可接纳，且只有1.5°给出“直退超限／匹配回正完成”；5–10 N时三个条件的两策略历史均完成且未超限。
- 480 Hz两例：参考插入阶段都出现13.150411 N腕力瞬时峰值，所以2–10 N全都在参考阶段先被拒绝，不能用其后续退出段支持这些预算的恢复可行性。该尖峰的100 ms均值峰值远低于瞬时值，但本实验规定的原始腕力门槛不能事后改用均值绕过它。

部分对齐控制在小于0.5 N的极窄历史区间也能出现策略差异，完整列在区间CSV中；这些是低负载控制细节，没有作为本轮优先卡滞验证案例。
