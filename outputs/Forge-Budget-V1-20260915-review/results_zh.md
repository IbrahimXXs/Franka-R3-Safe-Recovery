# 有限载荷预算：在线安全退出与超限退出验证

> 状态：全部完成。8 组条件、16 个计划分支中，13 个实际运行，3 个因参考阶段超限按计划未测。实际结果为 9 个预算内完成、1 个恢复超限、3 个参考阶段超限。全部闭合输出通过独立审计。这里的“安全”均指满足本实验记录阶段的数值、夹持和任务预算判据，不代表实物安全认证。

在 **目标深度 18 mm、孔—销接触对有效静／动态摩擦均为 1、命令倾角 1.5°、径向间隙约 0.2 mm、240 Hz** 下，新版实际按 **4 N 原始腕部合力预算**运行，得到：

| 原始信号／数值／夹持判据 | 有效／通过／保留 | 有效／通过／保留 |
| 4 N 预算结果 | **超限负例** | **预算内成功正例** |

两条路径各自在新进程中运行，**整个参考前缀与恢复起点均匹配**；忽略时钟列后，参考保存值逐字段相同。实际恢复起点深度为 **18.2279 mm**、倾角 **1.4391°**，区别于命令值。配对标签为 `paired_straight_overbudget_realign_safe`。这次是预先设置预算后的在线检测与中止，不是把旧的完整退出轨迹重新改标签。允许边界沿用 **F≤B 且 T≤1 N·m**；严格大于相应预算时停止，等于预算允许。

直接分支的第一次越界发生于恢复开始后 **0.720833 s**，属于 RETREAT；该帧腕部合力 **4.541491 N**，比预算高 **0.541491 N**。这一帧被保存，之后没有新的任务推进步。力矩约 0.07624 N·m，夹持平移滑移约 0.01652 mm，均没有触发各自限制。

到中止时，命令退出量为 **1.104648 mm**，相对参考末端的实际退出量为 **0.136718 mm**，已经存在明显跟随滞后。不能把旧 20 N／新 5 N 路径在此之后的轨迹填入本条 4 N 记录；本条路径没有继续执行，也没有观测其完整退出所需的最大力。

**这支持本次研究的概念验证：同一个已达到的机械状态，在给定较低任务载荷预算下，存在直接退出超限、换一条恢复路径可完成的情况。** 它没有证明该状态对所有策略都不可恢复，也没有证明销真的断裂或夹爪已经失效。比较起点是参考末端，调姿分支并不是接在直接分支的超限帧之后执行。

图：[4 N 两策略的力与实际位移](budget_candidate_4n_profiles.png)。各曲线到清孔或中止为止；直退只有约 0.72 s 恢复观测，不能把不同长度的曲线当作两条完整恢复成本比较。

本次标签依据原始逐帧峰值。100 ms 均值明显低于瞬时峰值，因此这些结果不能直接解释为持续静态卡死或持续需要 4 N 以上拔力；图中同时保留原始力和窗口均值，没有用平滑结果替换超限标签。

### 3.2 预算：3 N 太紧，4 N 能区分策略，5 N 两者均可完成

同一个 18 mm、1.5°、μ=1 命令路径在 **3 N** 下，参考保持阶段的 3.2289 N 就触发中止；因此还没有建立预算内的完整恢复起点。3 N 与 4／5 N 的共同参考前缀为 **2712 个样本**，忽略时钟列后保存值相同。

**4 N 与 5 N** 的完整参考轨迹各 2811 个样本相同，直接恢复的共同 **174 个样本**也相同，包括使 4 N 分支中止的 4.5415 N 那一帧。5 N 分支随后继续，在完整恢复中观测到峰值 4.5835 N 并清孔。这验证了预算改变的是允许继续执行的范围，不是人为缩放力曲线。5 N 的后续数据仍属于自己的分支。

### 3.3 嵌入长度和角度：本轮确实影响了结果

将目标深度从 **18 mm 降至 12 mm**，其余计划条件相同，直接退出从 4 N 超限变成完整退出，恢复峰值为 **0.3234 N**。两者实际参考末端深度为 18.2279／12.0509 mm，实际倾角为 1.4391／1.5244°；这是包含实际状态差异的深度对照，不能假设所有接触状态完全相同。

几何上，有效导向长度约为 16.7280／10.5511 mm；用实际倾角作简单的 `Lg × tan(θ)` 横向扫掠估算，分别为 **0.4203／0.2808 mm**，实际直径间隙约 **0.3980 mm**。这为深嵌入更容易接触两侧提供几何上的解释，但不是自锁、断裂或拔出力的判据。计算与来源见[导向长度核对](guide_span_audit.json)和[可复核脚本](audit_guide_span.py)。

18 mm、4 N 下，0° 和 1° 两策略均可退出；1.5° 出现策略相关正负例；2° 命令路径则在倾斜尚未完成时就以 4.6775 N 超限。该帧实际倾角仅约 **0.6413°**，命令倾角约 **1.4136°**，不能写成“已达到实际 2° 后卡死”。三组角度对照与对齐组到深度门槛的 2331 个样本，其实际状态与运动命令匹配。

**回正并非任何状态都更省力。** 12 mm 组回中回正的恢复全过程峰值 0.7859 N，高于直接退出的 0.3234 N；其纯退出峰值 0.6962 N 也更高。1° 组回中回正虽然降低纯退出峰值，但其整个恢复峰值 1.6037 N 仍高于直接退出的 1.0315 N。策略评价必须包含调整动作本身的成本。

### 3.4 摩擦：低摩擦组出现参考末帧突升，不能视作较大拔出阻力

μ 从 1 降到 0.5 后，本条轨迹在 HOLD 阶段、参考时间 **11.3042 s** 的末帧，从上一帧 **0.5324 N** 突升到 **8.9148 N**，随即中止。已观测 HOLD 段的完整 100 ms 窗口均值峰值仅约 **0.5057 N**。触发后没有继续运行，所以只能称“末帧突升”，无法确认随后是否回落或会持续多久。

该帧仍通过继承的数值和夹持筛查：接触最小间距约 −0.03412 mm、夹持平移滑移约 0.01551 mm。这不等于已经验证了真实接触力精度。这里没有拔出观测，不能据此推导“摩擦越小，拔出力越大”的规律。原始尾帧与窗口核算见[低摩擦事件核对](low_friction_terminal_audit.json)。

角度对照到深度门槛的共同前缀、3／4／5 N 的共同已观测前缀，以及深度／摩擦描述性对照，统一保存在[参数比较](parameter_comparisons.json)。相同种子不是匹配证据；这里比较的是逐样本实际位姿、速度、关节、夹持、力与命令。不同预算的长轨迹只用于独立对照，不补齐短轨迹。

## 4. 这个结果怎样对应有限夹持能力与易碎件

有限夹持能力与易碎性为较低允许载荷提供合理的任务动机。简化的双夹指准静态摩擦模型将切向承载能力与夹指摩擦及法向载荷联系起来，但本轮没有实测左右夹指的法向夹力，也没有标定工件强度，见[物理范围说明](../../docs/forge_budget_physical_scope_zh.md)。

本轮真正改变的是**任务监测预算**，不是实际夹爪驱动上限。运行时回读到的手指驱动上限仍为 40、刚度 7500、阻尼 173；这些是关节驱动参数，不能当作实测夹持力。销仍为刚体，没有断裂、塑性或疲劳模型。

腕部合力也不能代替局部接触应力：4 N 直退越界帧中，孔作用于销的法向载荷总和约 **22.6935 N**，腕部合力为 **4.5415 N**，两者不是同一种测量。较小净合力不能单独认证内部接触或脆性材料安全。当前销和机器人沿用禁用局部重力配置，没有在这轮完成真实传感器校准。

**预算覆盖从记录的 reference 初始样本起，到插入、STOP、回中回正、退出及清孔。** 场景初始化、抓取和其后 3 秒准备过程不受新预算监测，不能把“记录任务安全”扩大为“易碎件从抓取开始全程已验证安全”。预算是采样后中止规则，包含可见超调；本轮未验证实际机械臂刹停后的额外峰值。

上一轮发现的频率敏感性仍然存在。这里固定 240 Hz，没有将这组结果推广为 480 Hz 稳健性或 sim-to-real 成功证据。

主要 4 N 调姿正例的预算余量仅约 **0.2454 N**，也未经过独立扰动重复。下一阶段需要用实际夹持／工件承载测量标定预算，并检验接触参数、采样与求解设置变化下是否仍能区分策略。这些属于后续物理验证，本轮给出的结论是有限任务载荷下的仿真概念验证。

## 5. 如何把这些记录作为数据集使用

建议学习目标写为：**给定实际状态、载荷预算 B 和候选恢复策略，该策略是否能在预算内完成退出。** 预算必须作为输入，同一机械状态在 4 N 和 5 N 下出现不同标签并不矛盾。

| 输出 | 用途 |
|---|---|
| [每条件表](cases.csv) | 八组条件、两策略结果、完整前缀匹配和预算相关配对标签 |
| [每分支表](branches.csv) | 16 个计划分支，分别保留执行、未测、参考失败、恢复超限与未知 |
| [配对表](paired.csv)、[汇总](summary.json) | 单策略实测结果与匹配后的策略比较分开；失配不冒充负例 |
| [字段定义](schema.json) | 单位、预算信号、空值、分组和右删失解释 |
| [状态图](budget_outcomes.png) | 预算内完成、恢复超限、参考超限、未测和未知分别展示 |
| 原始实验的 `runs/<condition>/<policy>/` | reference／recovery 逐步 CSV、原始接触 gzip、首次越界事件、材质／几何／驱动回读及源码归档 |

`split_group_id` 和 `path_group_id` 保留共享物理路径的关系；相同插入前缀的角度、预算和策略记录应按组划分训练／测试，不能随机逐行拆分。单次确定性轨迹不足以估计真实失败概率。

对超限轨迹，保留触发帧、超调、实际位移和部分峰值；未执行阶段为 null。数值异常优先得到 unknown，夹持滑移与预算同时触发时单列混合约束。完整成本差只对两条匹配且完整清孔的路径计算。
