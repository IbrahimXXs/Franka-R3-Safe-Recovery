# 0.2 mm／30% 深度触发 +2°：120 Hz 与 240 Hz 独立诊断

## 结论

**定性现象复现：两次运行都在进孔后停止明显前进，直接退出时先积累载荷、实际运动滞后，随后成功清孔。姿态调整降低后续退出负载的方向也在两种步长下出现。**

**定量结果未收敛：240 Hz 的瞬时力峰更高，但 100 ms 平均退出力、持续高负载时间、阻力功和退出滞后均明显减小，力曲线更脉冲化。** 此外两次初态不同，因此本比较不能将所有变化单独归因于时间步。

## 范围与配置

仅分析已经关闭的 `insertion.csv` 和 `final_retreat.csv`，并在两次候选的终点测试完成后提取 `study.json` 中的策略汇总；没有读取正在写入的重放 CSV，没有更改物理源码、阈值或运行数据。

两次实际孔网格哈希完全一致，有效保守单边间隙均为 0.198994 mm；物理源码快照完全相同。配置差异为物理步长、相应 decimation/render interval、保持相同时间常数的腕部平滑系数，以及生成 USD 的文件路径。控制增益、摩擦及几何参数没有变化。

初始销三维位置相差 **0.203695 mm**，姿态相差 **0.069653°**；达到扰动触发点时，销位置仍相差 **0.061199 mm**。两次不是完全相同初态的步长试验。

### 进孔前的“首次停滞”不能称为孔内卡滞

240 Hz 自动检测的第一个事件位于 **2.629 s、深度 −9.744 mm**。原因是原检测只比较一段时间内命令与实际进度，没有要求插销已经进入孔内。这是接近阶段的跟踪滞后，不能用其恢复测试声称“卡滞恢复”。

从原始曲线独立筛选、要求当前和半秒前均在孔内，仍能找到 **8.242 s／13.649 mm** 的真实孔内进度停滞。随后直到 11 s，实际深度维持约 13.64 mm，命令继续达到 20 mm；因此进孔后停滞的定性判断不依赖错误的首事件。

## 240 Hz 力峰为何不能解释成更大的持续拔出力

实际退出腕力峰发生在恢复时间 **1.479167 s**。峰前后五个样本的腕力约为 **0.315、0.319、5.769、0.833、1.595 N**。该瞬时峰明显脉冲化，下一帧轴向接触力还发生方向改变。

不过它也不意味着完全没有持续阻力：100 ms 平均峰仍达 **1.748 N**，退出开始后实际位移滞后于目标约 **2.729 mm**。正确描述应同时保留“存在拔出阻力”和“单帧峰值对数值条件敏感”两点。

独立几何核查中，240 Hz 退出峰邻近的直孔壁越界约 **2.4–7.9 μm**，峰值帧约 **3.964 μm**；同期 PhysX 距离可能仍表现出接触缓存与已更新位姿之间的时序差异。局部越界比 120 Hz 减小，但尚不能据此证明完整物理精度。

## 终点两种策略：在各自运行内部进行匹配比较

两种步长下，候选终点的 `straight`、`realign` 重放均匹配，记录的各项匹配误差为零；四次策略测试均保持夹持、通过当前筛查并清孔。

| 物理频率／策略 | 停止峰值／100 ms | 对齐峰值／100 ms | 实际退出峰值／100 ms | 完整恢复峰值 | 清孔时间 |
|---|---:|---:|---:|---:|---:|
| 120 Hz 直接退出 | 3.333／0.627 N | — | 2.544／2.431 N | 3.333 N | 4.217 s |
| 120 Hz 先对齐 | 3.333／0.627 N | 1.073／0.701 N | 0.248／0.044 N | 3.333 N | 6.200 s |
| 240 Hz 直接退出 | 5.254／2.846 N | — | 5.769／1.748 N | 5.769 N | 4.217 s |
| 240 Hz 先对齐 | 5.254／2.846 N | 3.922／2.029 N | 0.842／0.070 N | 5.254 N | 6.175 s |

240 Hz 对齐后的退出接触阻力功从约 **0.00726 J** 降到 **4.86×10⁻⁶ J**。因此“调整姿态后退出更容易”的方向在本案例中有匹配状态证据；同时，对齐需要额外时间、对齐阶段自身有载荷，而且共同的停止阶段负载仍然存在。不能只引用 0.842 N 就把完整恢复描述成低于该值。

## 限制与可复现材料

- 当前重叠筛查允许约 49.75 μm，所有上述运行通过，但 **25% 是实验规则，不是已证实的物理精度门槛**。
- 独立核查使用局部孔壁平面越界，**不是完整网格穿透深度、材料形变或损伤量**。
- 相邻帧支持的接触缓存时序推断未获得 PhysX API 直接保证，本审计不做全局数据平移。
- 此次只有两个步长且初态不同，**没有证明数值收敛，也没有证明不可恢复状态或必须先对齐才能退出**。
- 本轮审计没有追加 480 Hz 或其他 GPU 运行。

数据和复现入口：

- `diagnostic_physics_audit.json`：精确指标、输入 SHA-256、配置与初态差异、终点策略摘要。
- `audit_physics_diagnostic.py`：读取已关闭数据重新生成上述 JSON。
- `diagnostic_240hz_insertion_geometry.json`、`diagnostic_240hz_retreat_geometry.json`：相邻帧独立核查结果。
- `geometry_audit/README.md`：几何脚本、冻结函数及原始 USD 的使用说明。
