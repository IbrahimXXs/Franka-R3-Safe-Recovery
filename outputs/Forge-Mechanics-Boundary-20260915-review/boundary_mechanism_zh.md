# 18 mm、1.5° 边界案例：接触机制与实际退出受阻

**结论：观察到可恢复的短时退出受阻与明显增大的直退载荷，尚不能称为不可恢复卡死或经实物标定的拔出力。** 本说明仅使用 `Forge-Mechanics-Boundary-20260915` 已完成的 0°、1°、1.5° 三例，240 Hz、名义径向间隙 .2 mm、μs=μd=1、目标深度 18 mm。旧中断的 480 Hz 目录和后续新实验未并入。

三例 states→regions→STOP 离线导出已刷新：33 个代表状态全部有观测。1.5° 案例原连续直退和匹配后的 realign 均通过本协议数值/夹持/安全筛查并最终 `cleared`。

## 1. 参考末端已形成两侧分离受载区，STOP 后仍保留

1.5° 命令的参考末端实际角度为 **1.439°**，深度 **18.228 mm**；参考最大 ΣN 为 **6.308 N**。这里 ΣN 是各接触点法向载荷之和，不能当作腕力或轴向拔出阻力。

下表每行的载荷、姿态、跨度和腕力均来自**同一帧**。上缘为孔底坐标 z≈24 mm 的入口过渡带；内壁为反侧直壁受载区。

| 状态 | 实际倾角 | 上缘 / 内壁法向载荷 | ΣN | 两侧质心轴向跨度 | 腕力 |
|---|---:|---|---:|---:|---:|
| 参考末端 | 1.439° | 1.858 / 1.840 N | 3.698 N | 16.628 mm | .452 N |
| STOP 末端 | 1.429° | .924 / 1.007 N | 1.931 N | 16.623 mm | .559 N |
| 直退法向载荷峰 | 1.415° | 14.404 / 8.289 N | 22.694 N | 16.492 mm | 4.541 N |
| 直退腕力峰 | 1.395° | 3.376 / 1.888 N | 5.264 N | 16.476 mm | 4.583 N |

参考末端下方内壁受载中心 z≈7.372 mm，直退腕峰时升至 z≈7.524 mm，上缘仍约 z=24 mm，与小幅退出及接触间距缩短相符。分区是原始法向接触点的加权区域估计，并非唯一配对的“两点接触”求解。将入口上缘排除的旧 strict-wall 指标不足以描述这里的两侧载荷。

## 2. STOP 降低了法向载荷，但腕力没有同步降低

实际执行了 60 步、0.25 s STOP。比较恢复前最后 100 ms 与 STOP 最后 100 ms：

- 平均 ΣN：**3.9039→2.3770 N，下降 39.1%**。
- 平均腕力：**.7259→.9521 N，上升 31.2%**。
- 两个窗口每帧都仍有法向接触；直退最初 100 ms 的平均 ΣN 仍为 **2.1101 N**。

因此不能把这个案例概括为“STOP 使所有力都下降”。STOP 将目标切换为测得的手部位姿：参考末端至 STOP 末端，深度减少 .00590 mm、倾角减少 .00996°、横向移动 .00697 mm。接触约束有所松弛，但未消失；腕部动态反力与法向载荷之和也不是同一个量。

## 3. 直退存在实际运动受阻，不只是载荷尖峰

直退目标采用 5 mm/s、0.5 s 平滑加速。以下比较共同的**直退开始后 0.50–0.75 s**，每例都观察完整 60 步。实际退出由测得的销深度变化计算，命令退出由日志目标深度变化计算。

| 命令倾角 | 命令退出 | 实际退出 | 实际平均退出速度 | 平均腕力 | 接触 Fz 有符号均值 |
|---|---:|---:|---:|---:|---:|
| 0° | 1.250 mm | 1.410 mm | 5.641 mm/s | .00754 N | 0 N |
| 1° | 1.250 mm | 1.441 mm | 5.764 mm/s | .02764 N | −.01617 N |
| 1.5° | 1.250 mm | **.02189 mm** | **.08756 mm/s** | **1.51418 N** | **−1.00514 N** |

0°/1° 的瞬时平均速度略高于命令巡航速度，是实际运动追赶前期跟踪滞后的结果。1.5° 在此窗口只完成约 1.75% 的目标位移增量；60 帧全部保留上缘与反侧内壁受载，平均区域载荷分别 **1.4320、1.3847 N**。这比单独报告一个力峰更能支持“短时退出进度近乎停滞”的判断。

在直退开始后 .667 s 的腕力峰帧，命令累计退出 **2.0833 mm**，实际相对 STOP 末端仅退出 **.1518 mm**；测得深度比目标深度大 **1.9256 mm**。同帧接触法向 Z 分量为 0，摩擦 Z 分量为 **−5.2491 N**，确实朝下、阻碍向上退出。

### 阻力是脉冲化的，不是恒定摩擦台阶

- 腕力峰为 **4.5835 N**；最大完整 100 ms 腕力均值为 **2.2026 N**。
- 该 100 ms 窗口中平均 ΣN=**4.2614 N**；接触 Fz 有符号均值 **−.85255 N**，正向截取的退出阻力 `max(0,−Fz)` 均值 **1.51122 N**。两个平均量定义不同，后者不能解释成净平均阻力。
- 相应窗口第一帧到最后一帧，目标退出 .47868 mm，实际仅退出 .01809 mm；它们的时间戳跨度为 95.833 ms，而均值按 24×1/240 s=100 ms 计算。
- 全直退过程中，向下阻力 >1 N 的最长连续记录只有 **4 帧、16.7 ms**。因此证据是“持续受载接触和显著运动迟滞，叠加反复阻力脉冲”，不是连续恒定 >1 N。

受阻随后自行解除：直退开始后 0.75–1.00 s 实际退出 **1.6940 mm**，1.00–1.50 s 又退出 **3.9456 mm**；最终脱离。原连续恢复最大夹持相对滑移为 **.03285 mm**，未触发 .1 mm 门槛；参考插入阶段的最大值另为 **.02332 mm**。

## 4. 匹配的 realign 提供了有用的策略对照，但要比较整个动作

此例 realign 的 replay 匹配成功，开始状态及 STOP 轨迹与原连续分支相符。调整结束时实际倾角约 **.170°**、ΣN=0；销深度也从 STOP 末端 18.222 mm 变为 **18.076 mm**，横向位置随姿态动作改变。因此这是完整姿态调整策略的效果，不能当作只改变一个角度且固定其他状态的因果实验。

| 量 | 原连续直退 | 先 realign 后直退 |
|---|---:|---:|
| 实际 retreat 阶段腕峰 | 4.5835 N | 1.1509 N |
| retreat 阶段最大 100 ms 腕力均值 | 2.2026 N | .08816 N |
| retreat 阶段最大 100 ms 正向退出阻力均值 | 1.51122 N | .000494 N |
| **整个恢复动作腕峰，包含 STOP/realign** | **4.5835 N** | **3.7546 N** |

realign 过程本身的腕峰为 2.2822 N，完整策略峰值出现在共享的 STOP。realign 后的 1.1509 N retreat 腕峰帧，接触摩擦 Z 分量其实向上，且实际深度瞬时增加，不能称其为 1.1509 N 的纯向上拔出阻力。

## 5. 可支持的研究结论与边界

本案例支持在**同一名义几何、深度与摩擦配置**下，较大的倾斜条件可出现分离受载区、短时退出受阻及更高直退载荷；可比较的姿态调整分支明显降低其后 retreat 阶段的阻力。但原连续直退也成功，当前不能标为“不可恢复卡死”或“超过 20 N 的退出失败”。尤其 **22.694 N 的 ΣN 峰不等于超过 20 N 的腕力或拔出力**。

当前最大报告接触重叠约 .02568 mm，低于本协议约 .04975 mm 的经验筛查值；通过筛查不等于数值误差已排除。刚体 SDF 接触、力/位姿帧内时序、单次样本、销与机器人禁重力配置，均限制实物外推。后续 480 Hz 复核结果应单列；本说明没有预先假定时间步不敏感。
