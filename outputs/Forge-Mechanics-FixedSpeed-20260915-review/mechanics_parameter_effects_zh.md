# 主矩阵参数效应：接触区域、持续载荷与 STOP 的观测范围

本说明对应 `Forge-Mechanics-FixedSpeed-20260915` 全部 **24 个已完成案例**。states 与 regions 各导出 264 行，其中 184 行有观测；STOP 审计覆盖全部 12 个倾斜案例。未修改冻结物理代码，也未把后续实验并入主矩阵。

## 1. 同 μs=μd=1，深度增加伴随接触形态变化

三个案例均命令倾斜 +2°，但实际姿态和参考结束原因不同。下表使用**各自参考末端的同一帧**；ΣN 是接触点法向载荷之和，不是腕部合力。

| 目标深度 | 实际深度 / 倾角 | 销基点 X / Y | 几何导向长度 Lg | 上缘 / 内壁法向载荷 | 两侧受载区质心轴向跨度 ℓ |
|---|---|---|---:|---|---:|
| 6 mm | 6.040 mm / 1.986° | +.0157 / −.0014 mm | 4.540 mm | 0 / 0 N | 无两侧受载观测 |
| 12 mm | 12.148 mm / 1.978° | −.1874 / +.0293 mm | 10.648 mm | .0614 / 0 N | 无两侧受载观测 |
| 18 mm | 18.161 mm / 1.513° | −.2265 / −.0014 mm | 16.661 mm | 5.781 / 4.125 N | 16.557 mm |

18 mm 案例的正 X 上缘受载中心位于孔底坐标 z≈24.000 mm，反侧内壁受载中心位于 z≈7.443 mm。其参考法向载荷峰时，两区分别承担 **12.703、8.295 N**，轴向跨度 **16.551 mm**。6/12 mm 各自法向载荷峰则分别为 **1.641、2.619 N**，所选峰值帧均是单侧上缘受载，没有相同的上下分离受载形态。

`Lg` 是按实际姿态截取的近似几何导向长度；`ℓ` 是受载区域加权中心的距离，只有两侧各达到 .01 N 才有效。两者不能互换。旧 `wall_both_sides_loaded` 排除了入口上缘，因此其 false 不能用于否定“上缘+反侧内壁”接触。

### 持续载荷，而非只看单帧峰

| 目标深度 | 参考末 100 ms 平均 ΣN / 腕力 | 末 100 ms 中 ΣN≥.01 N 的帧比例 | hold 中连续 ΣN>1 N 的最长观测支持 |
|---|---|---:|---:|
| 6 mm | 0 / .00227 N | 0% | .00417 s（1 帧） |
| 12 mm | .13382 / .18238 N | 45.8% | .00417 s（1 帧） |
| 18 mm | 13.58895 / 3.23542 N | 100% | .25833 s（62 帧） |

100 ms 采用 24 帧×1/240 s 的支持时长；第一帧到最后一帧时间戳跨度为 95.833 ms。阈值 .01/1 N 仅用于明确离线筛选，不是新的安全阈值。

这些结果支持：**本控制流程在 18 mm 嵌入附近出现分离受载区与持续较高法向载荷；6/12 mm 的接触更间歇。** 不能据此断言“嵌入越深，拔出力必然越大”。相较深度门通过时，三例参考末端的实际深度变化分别为 −.045、+.079、+.110 mm，X 位移分别为 +.168、−.032、−.123 mm，边界条件并不完全一致。6/12 mm 记录了约 1 s 的倾斜后 hold；18 mm 仅约 .296 s 就触发夹持滑移门槛，实际角度也没有达到 2°。

## 2. 四个 18 mm 倾斜案例都先触发夹持相对滑移门槛

| μs/μd | 末端实际角度 | 最大 ΣN | 末 100 ms 平均 ΣN | 最大腕力 | 末端夹持相对滑移 | 末端两区跨度 ℓ |
|---|---:|---:|---:|---:|---:|---:|
| .5/.5 | 1.505° | 19.486 N | 13.503 N | 6.231 N | .10423 mm | 16.644 mm |
| .75/.75 | 1.494° | 17.629 N | 13.467 N | 6.675 N | .10270 mm | 16.632 mm |
| 1/1 | 1.513° | 20.998 N | 13.589 N | 7.307 N | .10453 mm | 16.557 mm |
| 1/.5 | 1.511° | 16.108 N | 12.893 N | 5.655 N | .10204 mm | 16.620 mm |

四例参考末端均有上缘与反侧内壁受载，末 100 ms 每一帧 ΣN≥.01 N；夹持相对滑移超过 .1 mm 门槛后结束。原始 `grasp_lost` 是程序标签，**不能解释为销已掉落、已不可恢复卡死，或已完成一次失败拔出**。

四例的 `final_retreat.csv` 都只有复制的恢复 t=0 行，**没有执行 STOP，也没有执行直退**；realign 因参考不满足资格而未执行。离线表现在明确区分 `state_observed=true` 与 `phase_executed=false`，对应执行时长为 0。

最大 ΣN 与最大腕力列各取本信号峰值，通常不在同一帧。尤其 1/1 案例 ΣN=20.998 N 那帧，腕力仅 **2.389 N**，接触法向世界 Z 分量为 0，摩擦 Z 分量为 **+.931 N（向上）**，阶段仍是 hold。因此 **20.998 N 不是测得的 20 N 向上拔出阻力**。

摩擦档变化没有在这组单次案例中产生法向载荷的严格单调排序；也不能把差异归结为“摩擦设置没生效”。独立 `dynamic_friction_effectiveness_audit.json` 已核对运行时材质及对正滑动响应，支持 1/1 与 1/.5 的动态摩擦设置确实有区别。

## 3. STOP 的卸载现象只在实际执行过的案例中成立

四个 12 mm 倾斜案例均执行了 0.25 s 原连续直退前 STOP。下表比较**恢复前最后 100 ms**与**STOP 最后 100 ms**，不拿两个不同阶段的峰值相除。

| μs/μd | ΣN 均值：前→后 | 腕力均值：前→后 |
|---|---|---|
| .5/.5 | .07419→0 N | .08703→.00114 N |
| .75/.75 | .19385→.09237 N | .20595→.09170 N |
| 1/1 | .13382→0 N | .18238→.00185 N |
| 1/.5 | .16132→.00458 N | .19811→.01921 N |

这支持流程中存在卸载，但不足以推断强卡滞也会如此。6 mm 四例在恢复前末 100 ms 已是零法向载荷；18 mm 四例根本没有执行 STOP。最强接触状态尚未进入拔出比较。

STOP 将控制目标切换为当时测得的手部位姿，可能释放前一阶段的目标跟踪误差。以 12 mm、.75/.75 为例，STOP 中实际倾角只变 +.000585°、深度变 −.00795 mm，但横向仍移动 .02745 mm；不可称为完全相同的接触状态。没有“取消 STOP”对照时，也不能单独识别 STOP 的因果贡献。replay mismatch 的策略未获得可比较恢复曲线，不能当作恢复失败样本。

## 数据入口与范围

- `mechanics_states.csv` / `.schema.json`：实际状态、Lg、严格直壁测量与阶段执行标记。
- `mechanics_contact_regions.csv` / `.schema.json`：包括入口上缘的离线分区、两侧受载区及输入哈希。
- `mechanics_stop_unloading.json` / `.csv`：全部 12 个倾斜案例的端点、固定时间窗口和原始接触分区。
- 主矩阵 `study.json`、各例 `insertion.csv`：上述 hold 持续载荷计数和质量标签的来源。

这些是刚体接触仿真中的受载区估计，不是材料形变测量，也不是唯一配对的两点接触解。接触与位姿的帧内时序尚未通过引擎 API 保证直接确认；此审计未作全局帧移位修正。
