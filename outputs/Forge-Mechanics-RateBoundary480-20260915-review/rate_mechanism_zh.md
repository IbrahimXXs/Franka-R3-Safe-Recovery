# 480 Hz 机制复核：有退出阻力，但未复现 240 Hz 的近乎停滞窗口

**480 Hz 的 1.5° 案例仍出现退出滞后和较高瞬时拔出阻力，但没有复现 240 Hz 在直退开始后 .50–.75 s 的持续两侧受载与近乎停滞。** 两频率的初始状态不同，这不是固定初态的时间步收敛验证；目前既不能说定量结果稳定，也不能据此判定某个频率代表实物真值。

本说明仅使用已完成的 `Forge-Mechanics-RateBoundary480-20260915` 两例（0°、1.5°），与已完成的 `Forge-Mechanics-Boundary-20260915` 对应 240 Hz 案例比较。480 Hz 的 states、regions 各导出 22 行，全部有观测；两个策略均最终脱离，1.5° realign 的 replay 匹配成功。旧中断的 `Rate480` 目录不参与比较。

## 1. 相同退出时间窗口的运动与载荷

时间从实际 STOP 结束、进入 retreat 阶段起算。以下完整 .25 s 窗口，在 240/480 Hz 分别使用 60/120 个新物理步。

| 频率、命令倾角 | 命令退出 | 实际退出 | 平均腕力 | 平均接触 Fz | 两侧同时受载帧比例 |
|---|---:|---:|---:|---:|---:|
| 240 Hz、0° | 1.250 mm | 1.410 mm | .00754 N | 0 N | 未在此运动审计重算 |
| 240 Hz、1.5° | 1.250 mm | **.02189 mm** | **1.51418 N** | **−1.00514 N** | **100%** |
| 480 Hz、0° | 1.250 mm | 1.378 mm | .06767 N | −.04280 N | 未在此运动审计重算 |
| 480 Hz、1.5° | 1.250 mm | **.99526 mm** | **.69858 N** | **−.45636 N** | **0%** |

Fz 为接触作用在销上的有符号世界 Z 分量，负值阻碍向上退出。1.5° 的平均实际退出速度由 .08756 mm/s 变为 3.9810 mm/s；480 Hz 有跟踪滞后，但不是同等程度的近乎停滞。

该窗口中，480 Hz 的平均上缘载荷 .3091 N、平均内壁载荷 .2646 N，**不能因为两个时间平均值都非零就声称同一时刻存在两侧约束**：两侧各≥.01 N 的同时受载帧比例实际为零，且只有26.7%的帧有 ΣN≥.01 N。240 Hz 的60帧则全部同时存在两侧受载。

另外扫描了全部“命令在 .25 s 内退出至少1 mm、窗口起点仍在孔内”的完整 retreat 窗口，避免只检查固定时间而遗漏移位后的停滞：240 Hz 最小实际进度 **.02072 mm**；480 Hz 最小 **.33937 mm**。这是离线运动描述，不新增正式卡滞标签。

## 2. 两频率在 STOP 后走向不同接触状态

两者参考末端都观察到入口上缘与反侧内壁受载，但实际姿态不同：

| 量 | 240 Hz | 480 Hz |
|---|---:|---:|
| 参考末端实际深度 | 18.2279 mm | 18.3578 mm |
| 参考末端实际倾角 | 1.4391° | 1.3607° |
| 末端上缘 / 内壁法向载荷 | 1.8576 / 1.8401 N | 1.9129 / 1.6729 N |
| 末端两侧质心轴向跨度 | 16.6276 mm | 16.7633 mm |
| 参考末100ms平均 ΣN | 3.9039 N | 3.6073 N |
| STOP 末100ms平均 ΣN | 2.3770 N | **.004875 N** |
| STOP 末100ms平均腕力 | .9521 N | **.01262 N** |

480 Hz 的 STOP 末端 ΣN=0，随后 retreat 最初100ms也无法向接触。240 Hz 的 STOP 末端仍有两侧载荷，retreat 最初100ms平均 ΣN=2.1101 N。因而两者并不是从等价的接触状态开始退出。

480 Hz STOP 中实际倾角减少 .01054°、横向移动 .00854 mm、深度增加 .00355 mm；即使姿态变化较小，也伴随接触解除。不能把两频率差别仅解释成对同一连续接触力波形进行更密集采样。

## 3. 高瞬时腕峰保留，持续阻力与接触位置不相同

| 实际 retreat 阶段 | 240 Hz | 480 Hz |
|---|---:|---:|
| 0° 对照腕峰 / 最大100ms均值 | .3957 / .08199 N | 3.5687 / .36231 N |
| 1.5° 直退腕峰 / 最大100ms均值 | 4.5835 / 2.20260 N | 5.4911 / 1.00040 N |
| 1.5° 向下接触阻力峰 | 5.2491 N | 5.2971 N |
| 1.5° `max(0,−Fz)` 最大100ms均值 | 1.51122 N | .58650 N |

两个单次频率实验内，1.5° 的 retreat 腕力均值都高于各自0°对照；但峰值、均值、持续时间和接触拓扑不具有相同的跨频率变化，不能只据480 Hz峰更高称“阻塞复现”。

480 Hz 直退腕峰帧的实际倾角为 **1.2988°**、腕力 **5.4911 N**、接触摩擦 Fz **−5.2971 N**，法向载荷来自**单侧上缘**；该帧没有两侧同时受载。参考阶段另有 ΣN=20.6413 N 的峰，不能把这个法向载荷之和称为20 N拔出阻力，也不能移用到 retreat 阶段。

最大夹持相对滑移：240 Hz 原连续恢复 **.03285 mm**，480 Hz **.08325 mm**，均低于本实验 .1 mm 门槛，但后者姿态/夹持变化更大。两者最终直退成功，不是不可恢复卡死样本。

## 4. realign 需要评估全策略，不能只看其后直退

480 Hz 匹配的 realign 后，retreat 腕峰/100ms峰均值降为 **3.2293 / .27146 N**，低于原连续直退 **5.4911 / 1.00040 N**。但 realign 动作自身出现 **8.5201 N** 腕峰；原连续策略整个恢复峰为 **6.5270 N**（在STOP）。

因此，**“姿态调整后直退较轻”与“整个调整策略峰值更低”是两项不同结论**。本480 Hz案例只支持前者；后者不成立。两策略均通过当前20 N安全预算且脱离。

## 5. 初态与数值适用范围

对应案例初始销基点在两频率间相差 **.60886 mm**，姿态相差 **.15260°**；初始线速度/角速度也不同。240 Hz初始深度−14.8326 mm、X/Y=−.3832/+.0901 mm；480 Hz为−14.4969 mm、−.8758/−.0337 mm。这些初态来自各频率的 reset/prepare 过程。相同随机种子并未提供相同动力学初态。

所以当前结果说明**包含重置过程的整套流程对频率与实际接触路径敏感**，不能隔离为纯时间步效应或完成收敛证明。刚体SDF接触、未直接保证的接触/位姿帧内时序、禁用销/机器人重力与未进行实物标定等边界依然存在。
